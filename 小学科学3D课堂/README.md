# 小学科学 3D 课堂

> 面向小学科学的三维数字观察资源 · 单页应用 · 完全离线 · 双击即用

把「看不见的结构」变成可拖动、可标注、可探究的三维观察对象。所有资源与逻辑均在本地，**无需联网、无需 Node.js 或服务器**，直接双击 `index.html` 即可在浏览器中运行。

---

## ✨ 特点

- **单一入口，统一框架**：一个 `index.html`、顶部同一套领域导航，切换领域在同一页面内完成，不跳版本、不进子文件夹。
- **完全离线**：3D 模型与配图全部本地引用，双击即可运行。
- **观察式学习流程**：选择模型 → 自由观察 → 结构标注 → 比较解释 → 探究测验。
- **博物馆式排版**：纸张质感、暖色留白，桌面与移动端均可用。

---

## 🔬 内容领域

### ♧ 生命世界（绿）— 已开放
9 个人体器官 3D 模型 + 鲫鱼，支持自动旋转 / 缩放 / 聚焦 / 剖面 / 线框 / 复位，含结构热点标注、多尺度配图（位置 · 器官 · 显微 · 对比）与探究测验。
> 预留主题：常见生物、细胞世界。

### ◉ 地球宇宙（蓝）— 已开放
6 个独立 3D 地理互动课件（以 iframe 集成于同一页面）：中国地形、等高线、太阳视运动与正午太阳高度、二十四节气、月相、太阳系；点左侧观察库切换，支持全屏课堂。

### ⌬ 物质世界（紫）— 框架已搭，内容扩展中
预留：物质结构、分子运动、力与运动。

---

## 🚀 使用方法

1. Clone 或下载本仓库；
2. 双击目录中的 **`index.html`**；
3. 推荐使用最新版 **Microsoft Edge / Chrome**。

> 请保留整个文件夹结构，不要只复制 `index.html`——页面结构与资源都在同一目录内。

---

## 📁 目录结构

```
小学科学3D课堂/
├─ index.html                     单一入口
└─ assets/
   ├─ app.js / app.css            生命世界主逻辑（已内嵌 three.js）
   ├─ domains.js                  领域切换
   ├─ fish-swim.js                鲫鱼游动脚本
   ├─ earth-universe.js / earth.css  地球宇宙框架（geo 课件集成 · 样式）
   ├─ geo/                        6 个地理互动课件（自包含 HTML，内嵌 three.js）
   ├─ models/                     3D 模型（.model.js）
   └─ images/                     器官与鲫鱼配图（.webp）
```
