曾子易箦

全文引读

读这篇文章，可以从“一张席子为什么这样重要”入手。曾子病重将死，却坚持让人更换席子。他看重的不是席子本身，而是身份与礼义是否相称。

  • 看人物：曾子、乐正子春、曾元、童子的话有什么不同？
  • 看行动：曾子为什么必须“易箦”？
  • 看结尾：为什么换完席子，曾子反而“寝没而安”？
《礼记·檀弓上》

想一想

1童子为什么会说“华而睆”？这提示我们注意曾子的身份与席子之间的不匹配。
2曾元为什么不愿意马上换席子？从“病革”“不可以变”中找到他对父亲身体的担心。
3曾子为什么坚持“易箦”？可以从“得正而毙”四个字中寻找答案。

曾子寝疾，病。乐正子春坐于床下，曾元、曾申坐于足，童子隅坐而执烛。童子曰：“华而睆，大夫之箦与？”子春曰：“止！”曾子闻之，瞿然曰：“呼！”曰：“华而睆，大夫之箦与？”曾子曰：“然。斯季孙之赐也，我未之能易也。元，起易箦。”曾元曰：“夫子之病革矣，不可以变。幸而至于旦，请敬易之。”曾子曰：“尔之爱我也不如彼。君子之爱人也以德，细人之爱人也以姑息。吾何求哉？吾得正而毙焉斯已矣。”举扶而易之。反席未安而没。

行动线

童子发现席子华美 → 乐正子春阻止 → 曾子确认席子是季孙所赐 → 曾元劝阻换席 → 曾子说明“得正而毙” → 众人换席 → 曾子去世。

全文翻译

曾子卧病在床，病得很重。弟子乐正子春坐在床下，儿子曾元、曾申坐在父亲的脚边，一个童子坐在墙角，手里拿着烛火。

童子说：“这张席子花纹华美又有光泽，是大夫所用的席子吗？”乐正子春说：“别说了。”曾子听到了，吃惊地说：“呼！”童子又说：“这张席子花纹华美又有光泽，是大夫所用的席子吗？”曾子说：“是的，这是季孙氏赐给我的，我没有能够把它换掉。曾元，扶我起来，把席子换掉。”

曾元说：“您的病已经很危急了，不能移动。希望等到天亮，我再恭敬地换掉它。”曾子说：“你爱我还不如那个童子。君子爱别人，要用德行成全他；小人爱别人，却只顾着让他眼前安逸。我还有什么可求的呢？只希望能够按照正礼死去罢了。”众人扶起曾子，换了席子。席子换回来还没有放稳，曾子就去世了。

寺人披见文公

第一阶段·短篇入门·第2篇　·　出处：《左传·僖公二十四年》　·　点击金色词语查看注释

全文引读

读这篇文章，可以从“寺人披怎样说服晋文公”入手。他曾奉命追杀文公，却又在危急时刻主动求见。关注这场对话中的事实、道理与格局，就能读懂人物的复杂性。

  • 看背景：晋文公为什么不愿意见寺人披？
  • 看对话：寺人披怎样回应文公的责问？
  • 看转折：文公为什么从拒绝转为接见？
《左传·僖公二十四年》

想一想

1晋文公为什么拒绝接见寺人披？找出文公列举的两件往事，关注“即至”“中宿至”的时间对比。
2寺人披为什么说“君命无二”？他要说明自己当年是奉命行事，并非出于个人仇恨。
3“行者甚众，岂唯刑臣”表达了什么担忧？不能容纳有旧怨的人，离开晋国的不会只有寺人披一个。
4文公为什么改变了态度？寺人披的身份、能力和现实价值都成为转折依据。

吕、郤畏逼，将焚公宫而弑晋侯。寺人披请见。公使让之，且辞焉，曰：“蒲城之役，君命一宿，女即至。其后余从狄君以田渭滨，女为惠公来求杀余，命女三宿，女中宿至。虽有君命何其速也？夫袪犹在，女其行乎！”对曰：“臣谓君之入也，其知之矣。若犹未也，又将及难。君命无二，古之制也。除君之恶，唯力是视。蒲人、狄人、余何有焉？即位，其无蒲、狄乎！齐桓公置射钩，而使管仲相。君若易之，何辱命焉？行者甚众，岂唯刑臣？”公见之，以难告。晋侯潜会秦伯于王城。己丑晦，公宫火。瑕甥、郤芮不获公，乃如河上，秦伯诱而杀之。

行动线

寺人披求见 → 文公列举旧怨拒绝 → 寺人披说明奉命行事 → 以管仲劝文公放下旧怨 → 提醒不能容人会导致“行者甚众” → 文公转为接见 → 报告危局并化解灾难。

全文翻译

吕甥、郤芮害怕受到威胁，准备焚烧晋文公的宫室，杀死晋文公。寺人披请求进见。晋文公派人责备他，并且拒绝接见，说：“蒲城战役时，晋献公命令你第二天赶到，你当天就到了。后来我跟随狄国国君在渭水边打猎，你替惠公前来谋杀我，惠公命令你三天后到，你第二天晚上就到了。即使有国君的命令，为什么这样快呢？你的衣袖还在，你还是走吧！”

寺人披回答说：“我以为您回到晋国，已经懂得做国君的道理了；如果还没有懂得，就又要遭遇灾难。国君的命令不能有两样，这是古代的制度。替国君除掉他所憎恶的敌人，只看自己有没有力量完成任务。我只是奉命办事，并不是出于个人仇恨。现在您已经即位，难道还会永远把人分成‘蒲人’和‘狄人’吗？齐桓公不计较管仲曾经射中自己的衣带钩，却让管仲做宰相。您如果改变齐桓公不计前嫌、任用管仲的做法，将要离开的人很多，难道只有我这个受过宫刑的臣子吗？”

晋文公接见了他，寺人披把将要发生的灾难告诉了文公。晋文公秘密在王城会见秦穆公。后来宫室起火，瑕甥、郤芮没有抓到文公，秦穆公诱骗并杀掉了他们。

介之推不言禄

全文引读

读这篇文章，可以从“介之推为什么不愿意谈自己的功劳”入手。介之推曾在重耳流亡时帮助过他，但晋文公回国后，他没有主动求赏，反而带着母亲隐居。关注文中的对比、比喻和关键行动，读懂人物的选择。

  • 看对比：其他旧臣怎样谈论自己的功劳？
  • 看比喻：介之推把君臣关系比作什么？
  • 看行动：介之推为什么“遂隐而死”？
《左传·僖公二十四年》

想一想

1介之推为什么认为群臣“贪天之功”？联系晋文公复国的经历，想一想“天命”和“臣子功劳”分别指什么。
2介之推为什么不愿意去求赏？关注“尤而效之，罪又甚焉”和“不食其食”。
3“言，身之文也”是什么意思？介之推为什么把说出功劳看成给自己“装饰”？
4晋文公最后怎样评价介之推？“以志吾过，且旌善人”表现了文公怎样的态度？

晋侯赏从亡者，介之推不言禄，禄亦弗及。推曰：“献公之子九人，唯君在矣。惠、怀无亲，外内弃之。天未绝晋，必将有主。主晋祀者，非君而谁？天实置之，而二三子以为己力，不亦诬乎？窃人之财，犹谓之盗。况贪天之功，以为己力乎？下义其罪，上赏其奸；上下相蒙，难与处矣。”其母曰：“盍亦求之？以死谁怼？”对曰：“尤而效之，罪又甚焉！且出怨言，不食其食。”其母曰：“亦使知之，若何？”对曰：“言，身之文也。身将隐，焉用文之？是求显也。”其母曰：“能如是乎？与汝偕隐。”遂隐而死。晋侯求之，不获，以绵上为之田。曰：“以志吾过，且旌善人。”

行动线

介之推不主动谈禄位 → 认为群臣把复国功劳说成自己的 → 拒绝母亲“求赏”的建议 → 不愿用怨言为自己求名 → 与母亲隐居 → 晋文公以绵上作为祭田纪念他。

全文翻译

晋文公赏赐跟随他流亡的人，介之推不谈论禄位，禄位也没有给到他。他说：“晋献公有九个儿子，现在只有国君还在世。晋惠公、晋怀公没有亲近的臣子，国内外的人都背弃了他们。上天没有断绝晋国，必定会为晋国安排君主。主持晋国祭祀的人，不是国君还会是谁呢？这实际上是上天安排的，可是那几个人却把它当成自己的功劳，不是很糊涂吗？偷拿别人的财物，还要被称为盗贼；何况贪图上天的功劳，把它说成自己的功劳呢？下面的人把这种罪行说成合乎义，上面的人反而奖赏他们的奸诈；上下互相欺骗，这样就很难和他们相处了。”

他的母亲说：“你为什么不也去求取封赏呢？即使死了，又能怨恨谁呢？”介之推回答：“明知这种做法不对却又仿效它，罪过就更大了。况且说出怨恨的话，就不能再享用国君的俸禄了。”

他的母亲说：“那也让国君知道你的功劳，怎么样？”介之推回答：“言语，是身体的装饰；身体将要隐退了，还要用什么来装饰它呢？这就是想求得显达了。”他的母亲说：“你能这样做吗？那我和你一起隐居。”于是介之推就隐居而死。晋文公派人寻找没有找到，就把绵上作为祭田，说：“用来记下我的过错，并且表彰善人。”

全文引读

读这篇文章，最容易进入的方法是关注“展喜怎样让齐孝公自己得出退兵的结论”。展喜没有硬说鲁国强大，而是先承认百姓的害怕，再把话题转向先王盟约、齐桓公的职责和齐孝公的身份。

  • 看转折：展喜怎样区分“小人”和“君子”？
  • 看依据：为什么反复提到周公、大公和齐桓公？
  • 看结果：齐孝公为什么最后“乃还”？
《左传·僖公二十六年》

想一想

1展喜为什么说“小人恐矣，君子则否”？既承认现实处境，又为后面“依靠先王之命”的说理留下空间。
2为什么不直接夸耀鲁国强大？把劣势转化成道义上的优势，是展喜说理的关键。
3引用盟约和齐桓公旧事想提醒什么？齐孝公也是齐桓公的继承者，应承担维护诸侯关系的职责。
4展喜的说服为什么成功？可用“承认现实—提出依据—抬高对方身份—给出选择”复述。

夏，齐孝公伐我北鄙，公使展喜犒师。使受命于展禽。齐侯未入竟，展喜从之。曰：“寡君闻君亲举玉趾，将辱于敝邑，使下臣犒执事。”齐侯曰：“鲁人恐乎？”对曰：“小人恐矣，君子则否。”齐侯曰：“室如县罄，野无青草，何恃而不恐？”对曰：“恃先王之命。昔周公、大公，股肱周室，夹辅成王，成王劳之而赐之盟。曰：‘世世子孙，无相害也。’载在盟府，太师职之。桓公是以纠合诸侯而谋其不协，弥缝其阙而匡救其灾，昭旧职也。及君即位，诸侯之望曰：‘其率桓之功。’我敝邑用不敢保聚。曰：‘岂其嗣世九年，而弃命废职，其若先君何！君必不然。’恃此以不恐。”齐侯乃还。

行动线

齐军压境 → 展喜迎师 → 从“小人恐、君子不恐”说起 → 援引先王盟约和齐桓公旧职 → 齐侯意识到应承担职责 → 齐侯退兵。

全文翻译

夏天，齐孝公进攻鲁国北部边境。鲁僖公派展喜去慰劳齐军，并让他先到展禽那里接受指教。齐孝公还没有进入鲁国国境，展喜就跟随在他身边，说：“我们的国君听说您亲自屈尊来到敝国，将要光临敝国，所以派我这个臣下来慰劳您的属下。”

齐孝公问：“鲁国人害怕吗？”展喜回答：“普通百姓害怕，君子就不害怕。”齐孝公说：“你们家中空无所有，田野里连青草都没有，凭什么不害怕？”展喜回答：“依靠先王留下的命令。从前周公、大公辅佐周王室，帮助成王。成王慰劳他们，赐给他们盟约，说世世代代的子孙不要互相伤害。这件事记载在盟府中，由太师掌管。齐桓公因此集合诸侯，解决他们之间的不和，弥补他们的缺失，挽救他们遭遇的祸患，这是在彰明先王留下的职责。”

“等到您即位，诸侯都期望您继承齐桓公的功业。所以我们鲁国不敢守城抵抗，还说您一定不会抛弃先王的命令、废弃齐桓公的职责。我们正是依靠这一点而不害怕。”齐孝公于是退兵。

全文引读

读《马说》，不要只盯着“马”本身，要看千里马为什么没有机会证明自己。文章先写千里马需要特殊的食量，再写养马人不懂喂养、驱策和识别它，最后把责任推向“食马者”：问题不在世上没有人才，而在于有没有识才、爱才、用才的人。

  • 看对比：千里马的才能与普通马有什么不同？
  • 看因果：“才美不外见”的真正原因是什么？
  • 看反问：结尾怎样增强批评语气？
韩愈《杂说》·其四

想一想

1“千里马常有，而伯乐不常有”说明了什么？作者更感叹人才难得，还是更感叹识才的人难遇？
2千里马为什么“才美不外见”？按顺序找证据：喂养不当、力气不足、没有得到正确驱策。
3第三段连用三个“不”有什么作用？层层写出食马者的无知和错误。
4结尾为什么说“其真不知马也”？没有识别和使用人才的能力，却把责任推给千里马。

世有伯乐，然后有千里马。千里马常有，而伯乐不常有。故虽有名马，只辱于奴隶人之手，骈死于槽枥之间，不以千里称也。

马之千里者，一食或尽粟一石。食马者不知其能千里而食也。是马也，虽有千里之能，食不饱，力不足，才美不外见，且欲与常马等不可得，安求其能千里也？

策之不以其道，食之不能尽其材，鸣之而不能通其意，执策而临之，曰：“天下无马！”呜呼！其真无马邪？其真不知马也！

行动线

先说伯乐 → 写名马受辱 → 写喂养、驱策不当导致才华被埋没 → 食马者反而声称“天下无马” → 作者指出真正的问题是“不知马”。

全文翻译

环绕滁州的都是山。它西南方向的各座山峰，树林和山谷尤其秀美，远望那树木茂盛、幽深秀丽的，是琅琊山。沿山路走六七里，渐渐听到潺潺水声，从两峰之间倾泻而出的，是酿泉。山势回环、路也转弯，有一座亭子像鸟张开翅膀一样临立在泉上，这就是醉翁亭。建亭的是谁？山里的和尚智仙。给它命名的是谁？太守用自己的别号命名。太守和宾客来这里饮酒，稍微喝一点就醉，而年纪又最大，所以自号醉翁。

醉了能够同大家一起快乐，醒来能够用文章记述这件事的，是太守。太守是谁？是庐陵人欧阳修。

像那太阳出来，树林里的雾气散开；云气聚拢，山谷洞穴昏暗；明暗变化，是山间早晨和傍晚的景色。野花开放，散发清幽香气；好的树木枝叶茂盛，形成浓密绿荫；秋高气爽，霜色洁白；水位下降，石头露出，这些是山间四季的景色。早晨前往，傍晚回来，四季景色各不相同，快乐也没有穷尽。

至于背东西的人在路上歌唱，行路的人在树下休息，前面的人呼喊，后面的人应答，老人弯腰曲背、孩子由大人牵扶，来来往往络绎不绝，这是滁州人在游玩。到溪边捕鱼，溪水深、鱼肉肥；用酿泉水酿酒，泉水香甜、酒清；山中的野味和野菜杂乱地摆在面前，这是太守的宴席。宴饮的快乐不在于音乐；投壶的射中了，下棋的赢了，酒杯和酒筹交互错杂，起身坐下、大声喧哗，这是宾客们的欢乐。容颜苍老、头发花白，醉醺醺地倒在众人中间的，是太守醉了。

不久夕阳落在山头，人影散乱，太守回去，宾客跟随。树林枝叶浓密，鸟鸣声上上下下，游人离去，鸟儿就快乐起来。然而鸟儿知道山林的快乐，却不知道人的快乐；人们知道跟随太守游玩的快乐，却不知道太守把大家的快乐当作自己的快乐。醉了能够同大家一起快乐，醒来能够用文章记述这件事的，是太守。太守是谁？是庐陵人欧阳修。

余谪居于黄，过岐亭，适见焉。曰：“呜呼！此吾故人陈慥季常也，何为而在此？”方山子亦矍然，问余所以至此者。余告之故。俯而不答，仰而笑，呼余宿其家。环堵萧然，而妻子奴婢皆有自得之意。余既耸然异之。

独念方山子少时，使酒好剑，用财如粪土。前十九年，余在岐山，见方山子从两骑，挟二矢，游西山。鹊起于前，使骑逐而射之，不获。方山子怒马独出，一发得之。因与余马上论用兵及古今成败，自谓一世豪士。今几日耳，精悍之色犹见于眉间，而岂山中之人哉？

全文翻译

方山子，是光州、黄州一带的隐士。年轻时仰慕朱家、郭解的为人，乡里的侠客都尊奉他。稍大一些，改变志趣读书，想凭此在当世施展才华，却始终没有得到机会。晚年隐居在光州、黄州一带，住在岐亭。住茅草屋、吃素食，不和世人交往。丢弃车马，毁掉衣帽，徒步往来山中，没有人认识他。人们见他戴的帽子方形而高耸，说：“这难道是古代方山冠遗留下来的样式吗？”因此称他为方山子。

我被贬官居住在黄州，经过岐亭，恰好遇见了他。我说：“唉！这是我的老朋友陈慥季常啊，为什么会在这里呢？”方山子也惊讶地看着我，问我到这里来的原因。我把原因告诉了他。他低头不回答，继而仰天大笑，请我住到他家去。他家四壁空空，然而妻子、儿女和奴婢都显出怡然自得的样子。我对此感到十分惊奇。

我独自想起方山子年轻时，酗酒任性，喜好剑术，挥金如土。十九年前，我在岐山，见到方山子带着两名骑马的随从，身藏两支箭，在西山游猎。一只喜鹊在前面飞起，他让随从追赶射鹊，没有射中。方山子纵马独自冲出，一箭射中。于是他就在马上和我谈论用兵之道和古今成败之事，自认为是当世豪杰。如今才过了多少日子，精明强干的英气还显现在眉宇之间，哪里像是住在山中的人呢？

然而方山子家世代有功勋，本该得到官职，假如他置身仕途，如今早已显达闻名了。他的家在洛阳，园林宅舍雄伟壮丽，与公侯之家相当。在河北还有田地，每年可得上千匹帛，也足以使生活富裕安乐。这些他都抛弃不用，独自来到偏僻的深山，这难道不是因为他内心有所领悟才这样的吗？

我听说光州、黄州一带有很多奇人异士，常常假装疯癫、污浊不修边幅，无法见到他们；方山子或许能见到他们吧？
