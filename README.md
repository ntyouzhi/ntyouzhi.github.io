# 有志 · 互动作品集

一个纯前端的**个人网页导航首页**，也是这个 vibe coding 站点的作品索引层。
它只做一件事：把散落在仓库里的一个个独立网页，收拢成一页可搜索、可点开的目录。

- 线上地址：<https://code.ntcyz.cn/>
- 内容定位：面向真实教育现场的工具与互动作品——教学、学习、教研、校务
- 使用门槛：零。全部是单个 HTML 文件，浏览器打开即用，不装东西、不注册账号
- 联系：<ntcyz@126.com>

## 仓库构成

仓库根目录只有三个文件，职责分离得很干净：

| 文件 | 职责 |
| --- | --- |
| `index.html` | 首页本体。页面结构、样式、渲染逻辑、以及一份内置兜底作品清单，全在这一份文件里 |
| `works.json` | 作品清单数据。首页运行时读取它来渲染卡片，改内容不必碰代码 |
| `README.md` | 本说明 |

## 首页具备的能力

- **实时搜索**：对文件名、标题、简介、标签做关键词过滤，输入即生效；搜索时卡片编号仍按全局位置显示，不会错乱
- **最新优先**：清单末尾的一项会渲染成首页第一张卡片，编号 `01` 恒等于最新作品
- **响应式**：三列 → 两列（窄屏）→ 单列（手机），断点 820px / 560px
- **新标签页打开**：作品不覆盖首页，看完可以直接回去
- **手动刷新**：点「刷新列表」重新拉一次清单，无需重载页面
- **空态与提示**：搜不到时给出换词提示；清单读取失败时状态栏说明当前用的是哪份数据

## 设计与实现

没有构建步骤，没有框架，没有依赖，`index.html` 可以直接双击本地打开。几处关键取舍：

- **数据与展示分离**：运行时 `fetch('works.json')`，并带时间戳参数 + `no-store` 规避浏览器缓存，改完刷新即可见
- **兜底清单**：`works.json` 读取失败（网络、跨域、格式错误）时，自动回落到 `index.html` 内置的同名清单，保证首页永远不空白；代价是两处清单需同步维护
- **渲染层反转**：倒序通过 `works.slice().reverse()` 在渲染时得到，数据始终保持「按添加先后追加」的写法，不需要人工排序
- **输出转义**：所有来自 JSON 的字段写入 DOM 前统一转义 `& < > " '`，避免清单里的特殊字符破坏页面
- **逐卡片埋点**：每张卡片带 `data-goatcounter-click` 事件名（形如 `work-click/文件名`），可以单独看到某个作品的点击量
- **访问统计**：接入 GoatCounter（`ntcyz.goatcounter.com`），页脚拉取 `TOTAL.json` 展示累计访问数，读不到时显示占位符而不报错
- **基础 SEO**：`meta description` 与指向 `https://code.ntcyz.cn/` 的 `canonical`

## 部署

把 `index.html` 与 `works.json` 放在站点根目录（与其他作品 HTML 同级）即可生效，无需任何服务端配置——
首页是纯静态渲染，唯一的运行时请求是读同目录下的 `works.json` 和访问统计接口。
