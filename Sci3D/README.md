# 小学科学 3D 课堂

> 面向小学科学的三维数字观察资源 · 统一课堂入口 · 本地资源 · Godot 鲫鱼运动观察

把「看不见的结构」变成可拖动、可标注、可探究的三维观察对象。所有资源与逻辑均在本地，无需联网。静态标本可双击 `index.html`；含 Godot 鲫鱼运动的完整课堂，通过 `godot-fish/运行网页版.cmd` 启动后在浏览器访问。

---

## ✨ 特点

- **单一入口，统一框架**：一个 `index.html`、顶部同一套领域导航，切换领域在同一页面内完成，不跳版本、不进子文件夹。
- **完全离线**：3D 模型与配图全部本地引用，双击即可运行。
- **观察式学习流程**：选择模型 → 自由观察 → 结构标注 → 比较解释 → 探究测验。
- **博物馆式排版**：纸张质感、暖色留白，桌面与移动端均可用。

---

## 🔬 内容领域

### ♧ 生命世界（绿）— 已开放
人体观察库包含静态器官观察与“人的呼吸器官”动态场景。静态模型支持自动旋转、缩放、聚焦、剖面、线框、复位及结构热点；呼吸器官通过 Godot 展示鼻到双肺的完整通路、肺与胸廓及膈肌协调运动、空气流向，支持暂停、慢放、结构标注和器官选择。鲫鱼使用 Godot 水下运动场景，在场景中持续游动，支持滚轮缩放、拖动观察与复位，并标注鳃盖和五种鱼鳍。
> 预留主题：常见生物、细胞世界。

### ◉ 地球宇宙（蓝）— 已开放
6 个独立 3D 地理互动课件（以 iframe 集成于同一页面）：中国地形、等高线、太阳视运动与正午太阳高度、二十四节气、月相、太阳系；点左侧观察库切换，支持全屏课堂。

### ⌬ 物质世界（紫）— 框架已搭，内容扩展中
预留：物质结构、分子运动、力与运动。

### ⚙ 技术工程（棕橙）— 已开放
现有「自行车结构探索」「联合收割机结构探索」「手摇卷笔刀结构与功能」三个作品：均以单文件离线课件通过 iframe 接入，支持整机观察、拆分结构、零部件名称标注、五个子系统独立观察与运行演示。手摇卷笔刀依据教材 P38–40 重建，呈现夹持推进、齿轮传动、滚刀切削和木屑收集过程。
> 预留主题：简单机械、工程设计。

## 🚀 使用方法

1. Clone 或下载本仓库；
2. 双击 **`godot-fish/运行网页版.cmd`**，再打开 [本地课堂](http://127.0.0.1:8765/)；普通静态标本也可双击 `index.html`；
3. 推荐使用最新版 **Microsoft Edge / Chrome**。

> 请保留整个文件夹结构，不要只复制 `index.html`——页面结构与资源都在同一目录内。

## Godot 鲫鱼运动原型（分步开发）

新增独立工程 `godot-fish/project.godot`，复用现有鱼模型，使用 Godot 骨骼与曲线路径。
默认持续游动，支持拖动观察与复位，包含清浅水下环境、各鳍与鳃盖运动及科学标注。详见 [观察说明](godot-fish/README.md)。
已导出网页到 `assets/godot-fish/`；需 HTTP 服务访问。本机双击 `godot-fish/运行网页版.cmd`，再打开 http://127.0.0.1:8765/。

## 人的呼吸器官动态观察（第一版）

复用同一课堂入口和启动器。选择“人的呼吸器官”，或打开 [直接观察入口](http://127.0.0.1:8765/?observe=respiratory)。沿用原肺模型的完整网格和三张细节贴图，在原表面上进行呼吸形变。默认展示肺表面，“气道透视”显示补建的内部气道示意；空气粒子颜色表示方向。肺泡放大交换场景留待后续版本。

工程在 `godot-respiratory/`，网页导出在 `assets/godot-respiratory/`；详见 [观察说明](godot-respiratory/README.md)。已验证呼吸运动、暂停、慢放、开关、标注选择、缩放、复位、全屏、课堂切换及平板和手机布局。
